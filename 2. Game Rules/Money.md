This game uses the silver standard.  For simplicity, 1 silver is equal to 10 copper; 10 silver is equal to 1 gold.  For play aids, using pennies and dimes are helpful.  Silver dollars are a bit rare, so perhaps using quarters or some other coin would work.

|           |          |
| --------- | -------- |
| 10 Copper | 1 Silver |
| 10 Silver | 1 Gold   |
