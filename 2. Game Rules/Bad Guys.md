Ranking of bad guys from lowest to highest:

|           |
| --------- |
| Vermin    |
| Minion    | 
| Champion* |
| Boss      |


( * Alternate names: Champion/Lieutenant/Veteran/Elite )


Vermin and Minions essentially have one hit point each.

Champions and Bosses use the normal wound rules.


Small creatures should be able to take up two to a square instead of the usual 1 per 1.

For swarms you can:

1. Use fire!  Throw a couple of Molotov cocktails (Lanterns, Fireballs, Holy Hand Grenades, etc.) and the swarm will disperse.
2. Wade in!  Each character that goes in (or is attacked by surprise) rolls 2d6.  This is the number of creatures killed.  On a 1 or 2 however, the PC takes a STR 1d3 Wound.  The total number of the swarm is 5 x 2d6.
